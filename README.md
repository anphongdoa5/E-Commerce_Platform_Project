# System Analysis & Design: Điện Máy Xanh Online Purchasing System

Academic systems analysis and design project for an end-to-end online purchasing system for Điện Máy Xanh, a Vietnamese consumer electronics retail chain — covering requirements gathering, process/data modeling, use case specification, and UI design.


## Project Overview

As retail shifts from in-store to online purchasing, Điện Máy Xanh needs a comprehensive online purchasing system to stay competitive: a convenient shopping platform for customers, paired with efficient back-office operations — order processing, inventory control, and customer behavior tracking. This project analyzes and designs such a system end-to-end, from requirements gathering through interface design, covering account management, product search/browsing, cart, checkout, order tracking, reviews, and customer support.

## Key Deliverables

- **Requirements specification** — functional requirements (account & auth, product search/browsing, cart, order & payment, order tracking, reviews & feedback, customer support) and non-functional requirements (data security, performance, scalability, compatibility, usability, technical support)
- **Field survey** — interview-based survey design and execution across four stakeholder groups: customers, store managers, delivery staff, and customer support staff, with findings synthesis
- **Business process modeling** — end-to-end business workflow documentation
- **Data flow diagrams (DFD)** — context diagram, Level 0, and Level 1 diagrams for account management, product management, ordering, order management, and delivery management
- **Data dictionary** — full specification of data flows, data stores, and physical structure (PS), plus process specifications
- **Use case model** — 5 use case diagrams with full specifications: Order Placement, Account Management, Payment Management, Delivery Management, and Order Management
- **Entity-Relationship Diagram (ERD)** — full data model with entity descriptions
- **UI design** — 22+ screen mockups covering login, registration, password recovery, homepage, account management, product details, cart, checkout, order confirmation, order tracking, customer management, order management, and statistics/reporting
